How this works

  1. 1
    Split and encrypted. Files on Autonomi are split into encrypted chunks spread across many nodes.
  2. 2
    Fetched directly. Your browser finds the nodes holding this file and fetches the chunks from them. No server sends you the file.
  3. 3
    Verified and reassembled. Each chunk is checked, the file is put back together, and downloading is free.

The nodes serving the file can see your IP address, like any peer-to-peer download.
